# 项目设定：守城（南宋末）

> 本文件只保存**这个项目专属**的设定。
> 通用生产规则见 `.cursor/rules/ai-video-production.mdc`，不要往规则里塞项目细节。

## 时代与地域

- **南宋末年**，孤城，外城已破。
- 服化道必须配得上宋代，禁用明清元素。

### 服化道清单

| 类别 | 内容 |
|---|---|
| 甲胄 | 山文甲、步人甲、兽首吞肩 |
| 头盔 | 将军：凤翅兜鍪；士兵：普通铁盔（两侧无金色翼形装饰） |
| 服饰 | 交领右衽麻布战袄、革带、行縢绑腿 |
| 建筑 | 夯土包砖城墙、宋代城楼（举折平缓、斗拱疏朗）、木栅、望楼 |
| 器物 | 床子弩、火药罐、拒马、连枷 |
| 称谓 | 「都指挥使」「将军」「都头」「弟兄」 |

**禁用**：马蹄袖、顶戴花翎、飞鱼服、马褂、厂字襟。

## 人物

### 杨都指挥使（主角）

五十岁上下，清瘦长脸、颧骨微高、眼窝深陷、花白短须、鬓角霜白，左颊无疤。
戴凤翅兜鍪，穿深色山文甲、灰褐麻布战袍、破损灰绿披风、革带、行縢，腰间横刀。
性格：眼神沉、少动，说话慢，不被说动时连头都不转。

定妆照：`10-refs/char-general.png`
头像：`10-refs/char-general-head.png`

### 老兵陈七（劝退者）

四十岁上下，方脸、下颌宽厚、颧骨宽、眉骨重压、短硬胡茬、左颊无疤、单眼皮。
戴普通铁盔，穿步人甲、赭红战袄，前臂缠旧白绷带，腰间短刀。
性格：直、急，报败讯时抢字。

定妆照：`10-refs/char-veteran.png`
头像：`10-refs/char-veteran-head.png`

### 年轻兵张小乙（随从）

二十岁前后，圆脸、鼻梁塌、单眼皮、小眼、嘴唇略厚。
戴铁盔（常歪），穿步人甲、土黄短袄，身形单薄。

定妆照：`10-refs/char-young.png`
头像：`10-refs/char-young-head.png`

## 场景空间

内城墙顶的马道。**关键方位**：

- 将军面朝**城外**（垛口、平原、烟柱）
- 老兵面朝**城内**（下坡马道、拱形门洞、木构屋顶）

因此：

- 拍将军正脸 → 背后是城外方向 → 用 `10-refs/bg-toward-field.png`
- 拍老兵正脸 → 背后是城内方向 → 用 `10-refs/bg-toward-city.png`

## 光影设定

- 时间：黄昏将尽，冷青灰天光。
- 主光：火把暖橙硬光，只勾头盔与肩甲轮廓。
- 面部落在暗部，**不补暖光**。

## 剧情节拍

1. 外城破，溃兵涌入内城墙下
2. 老兵报败讯（回来的不到三成）
3. 将军不听，一句「城后头，还有六万口人」
4. 俯视城内，把「六万人」变成画面
5. 老兵低头改口
6. 将军转身，下令搬箭
